# 🎓 University RAG Assistant — IFNTUOG

An intelligent question-answering system built for Ivano-Frankivsk National Technical University of Oil and Gas. Students can ask questions in natural language and receive accurate, source-backed answers drawn from official university documents and the university website.

---

## ✨ Features

- **Conversational AI** — ReAct-based agent with multi-turn dialogue memory per chat session
- **Semantic search** — FAISS vector store with L2 similarity search over indexed university documents
- **Multi-format ingestion** — supports PDF, DOCX, and HTML (website scraping)
- **Academic context** — agent personalizes answers based on the user's faculty, department, and group
- **Chat management** — create, rename, and delete independent chats; titles are auto-generated by the LLM
- **University-restricted access** — registration limited to `@nung.edu.ua` email addresses
- **Admin panel** — document upload, URL indexing, index rebuild, and dialogue monitoring via Django Admin
- **Incremental indexing** — `state.json` tracks already-indexed documents to avoid redundant reprocessing
- **Fully local embeddings** — `nomic-embed-text` via Ollama; no paid embedding API required

## 🚀 Getting Started

### Prerequisites

- [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/)
- A Google AI Studio API key ([get one here](https://aistudio.google.com/))

### 1. Clone the repository

```bash
git clone https://github.com/your-username/university-rag.git
cd university-rag
```

### 2. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in the required values:

```env
SECRET_KEY=your-django-secret-key
DEBUG=False

POSTGRES_DB=ragdb
POSTGRES_USER=raguser
POSTGRES_PASSWORD=your-db-password

GOOGLE_API_KEY=your-google-ai-studio-key

OLLAMA_BASE_URL=http://ollama:11434
```

### 3. Start the services

```bash
docker compose up --build
```

This will start three containers:
- `web` — Django application (port `8000`)
- `db` — PostgreSQL
- `ollama` — Ollama embedding service (port `11434`)

### 4. Run migrations and create a superuser

```bash
docker compose exec web python manage.py migrate
docker compose exec web python manage.py createsuperuser
```

### 5. Pull the embedding model

```bash
docker compose exec ollama ollama pull nomic-embed-text
```

### 6. Access the application

| URL | Description |
|---|---|
| `http://localhost:8000` | Main application |
| `http://localhost:8000/admin` | Django Admin panel |

## 🗂 Adding Documents (Admin)

1. Log in to `/admin` with your superuser credentials
2. Navigate to the **Documents** section
3. Upload a PDF or DOCX file, or provide a URL to an HTML page
4. Click **Index** — the pipeline will chunk, embed, and store the document automatically
5. To update the knowledge base after changes, use the **Rebuild Index** action

## 🔒 Access Control

Registration is restricted to `@nung.edu.ua` email addresses. Each user specifies their **faculty**, **department**, and **group** in their profile, which the agent uses to provide contextually relevant answers without requiring the user to repeat this information in every query.
